
# solana wallet DApp

This is a simple decentralized application (DApp) built on the Solana blockchain using React, Vite, and Solana Wallet Adapter. The app allows users to request an airdrop, view their wallet balance, and send transactions.

## Features

- Request Airdrop: Allows users to request an airdrop of SOL tokens on the Solana devnet.
- View Balance: Displays the current balance of the connected wallet.
- Transaction: Lets users send SOL to other wallets.

## Technologies Used
- React: JavaScript library for building user interfaces.
- Vite: Next-generation build tool that provides fast, optimized development.
- Solana Wallet Adapter: A framework for integrating various Solana wallets into web applications.
- @solana/web3.js: JavaScript library for interacting with the Solana blockchain.
- @solana/wallet-adapter-react: React hooks for integrating Solana wallets.
